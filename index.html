Как установить

1. Установи Fabric (или Forge).
2. Скачай мод по кнопке выше — загрузка начнётся сразу.
3. Перемести скачанный .jar в папку .minecraft/mods.
4. Зайди на сервер play.your-server.ru.
5. Нажми V для настроек голоса в игре.
